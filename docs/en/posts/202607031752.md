# AstrBot Plugins

I developed several useful plugins for AstrBot, covering message forwarding, meme extraction, and LLM balance queries.

## MsgForward — Cross-platform Message Forwarding Plugin

[astrbot_plugin_msg_forward_cc](https://github.com/XTsat/astrbot_plugin_msg_forward_cc)

Cross-platform message forwarding plugin for synchronizing messages and bridging group chats across different platforms, with multi-platform support, source labeling, WebUI configuration, and message filtering.

[Read More](../guide/astrbot/MsgForward.md)

## MemeGrabber — Meme Extraction Plugin

[astrbot_plugin_meme_grabber](https://github.com/XTsat/astrbot_plugin_meme_grabber)

Meme extraction plugin for extracting QQ memes into savable file formats, supporting multiple formats, batch extraction, and custom naming.

[Read More](../guide/astrbot/MemeGrabber.md)

## LLM Balance — Multi-platform Balance Query Plugin

[astrbot_plugin_llm_balance](https://github.com/XTsat/astrbot_plugin_llm_balance)

Multi-platform LLM balance query plugin supporting balance/usage queries for DeepSeek, Silicon Flow, Moonshot, OpenAI and more.

[Read More](../guide/astrbot/LLMBalance.md)
