# limitPNG2 压缩图片

今天在批量压缩我的 Png 图片，嫌弃 limitPNG2 有点慢，去试了一下 gluttonyPNG ，结果有几个图片压缩完之后直接没了，因为软件是覆盖模式，所以直接把我的原图删了

所以我又去看了一下 limitPNG2 的 Fork，只看到近期有个琴梨梨的线程优化，但是我打包后发现用不了，我就自己重新改了一下线程，限制支持 64 线程，顺便优化了一下多线程的卡顿

发布在 [XTsat/limitPNG](https://g-++++ithub.com/XTsat/limitPNG)
