# CompactGUI 国际化版本

CompactGUI 是一个基于系统 Compact 功能的 GUI 工具，内置了 Steam 游戏数据库，可以一键查询 Steam 游戏的可节省数据大小。

我在 CompactGUI 的个人分支中添加了多语言支持，现在支持中文和英文。

并且改进了一个可能触发崩溃的潜在 bug，即加载数据库错误导致的崩溃。

解决方法是将数据目录修改到了本地，方便重新建立数据库，顺便方便了直接打包数据库和设置分享给别人。

发布在 [XTsat/CompactGUI](https://github.com/XTsat/CompactGUI_i18n)
