# LM-Speed-X

[LM-Speed-X](https://github.com/XTsat/LM-Speed-X) 是一个 LLM API 测速工具，Fork 自 [nexmoe/lm-speed](https://github.com/nexmoe/lm-speed)，支持 OpenAI 兼容 API、DeepSeek、硅基流动、腾讯云等多个服务商的速度测试。
::: tip 在线体验
前往 [lm-speed-x](https://lm-speed-x.xtsat.cc.cd/) 在线使用
:::

原版工具虽然功能完善，但需要依赖 PostgreSQL 数据库运行，部署门槛较高。我在原版基础上进行了一系列改进，使其更加易用：

- **去除数据库依赖**：将数据存储改为浏览器 localStorage，无需部署数据库即可使用，大大降低了部署门槛
- **本地排行榜**：新增本地测速排行榜功能，支持自定义筛选、数据导出导入，方便横向对比不同 API 的性能
- **配置导入导出**：支持一键导出/导入测试配置，方便保留共享测试流程
- **URL 参数快速测试**：支持通过 URL 参数直接传入 `baseUrl`、`apiKey`、`modelId`，无需手动填写表单即可快速发起测速

  格式：
  ```
  https://lm-speed-x.xtsat.cc.cd/?baseUrl=<YOUR_BASE_URL>&apiKey=<YOUR_API_KEY>&modelId=<YOUR_MODEL_ID>
  ```
  [以 DeepSeek 官方 API 为例](https://lm-speed-x.xtsat.cc.cd/?baseUrl=https://api.deepseek.com/v1&apiKey=sk-xxx&modelId=deepseek-v4-pro)：
  ```
  https://lm-speed-x.xtsat.cc.cd/?baseUrl=https://api.deepseek.com/v1&apiKey=sk-xxx&modelId=deepseek-v4-pro
  ```
  三个参数均为必填，页面会自动开始测速。

测速采用五轮连续压力测试机制，使用 tiktoken 精确计算 token 数，覆盖首 token 延迟、响应时间等核心指标，并自动生成性能分析报告。

如果需要本地部署，可以一键 fork 到本地使用 pnpm docs:dev 启动本地服务，即可在浏览器中访问。
